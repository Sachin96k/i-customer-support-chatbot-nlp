# AI-Based Customer Support Chatbot Using NLP

A learning project built with Python, Flask, NLTK-compatible NLP concepts, TF-IDF, and Logistic Regression. The web interface is built with HTML, CSS, and JavaScript.

## Features
- Intent classification using TF-IDF features and Logistic Regression
- Customer-support responses stored in `intents.json`
- Responsive web chat interface and quick-question buttons
- Low-confidence fallback response
- Basic input validation and health endpoint
- Unit tests for core web behavior

## Requirements
- Python 3.10 or newer recommended
- pip
- VS Code or another Python editor

## Setup on Windows (PowerShell)
1. Extract the ZIP and open the `ai_customer_support_chatbot` folder in VS Code.
2. Create a virtual environment:
   ```powershell
   py -m venv .venv
   ```
3. Activate it:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```
   If PowerShell blocks activation, you can use `.\.venv\Scripts\python.exe` directly or follow your organization's approved PowerShell policy.
4. Install dependencies:
   ```powershell
   python -m pip install -r requirements.txt
   ```
5. Train the NLP model:
   ```powershell
   python train.py
   ```
6. Start the web app:
   ```powershell
   python app.py
   ```
7. Open `http://127.0.0.1:5000` in your browser.

## Run tests
After installing dependencies and training the model:
```powershell
python -m unittest discover -s tests
```

## Add new customer-support topics
Edit `intents.json`. Each intent has:
- `tag`: unique label
- `patterns`: sample user questions for that intent
- `responses`: possible answers

After changing training patterns, run `python train.py` again and restart the server.

## Important limitations
- This is a demo, not a production customer-support platform.
- Responses are selected from a fixed knowledge base; the chatbot does not access real orders, payment systems, or customer accounts.
- Training examples are small, so classification may be wrong for unfamiliar wording.
- The confidence threshold is a simple heuristic and should be calibrated using a representative validation dataset.
- Do not collect passwords, OTPs, card details, or sensitive personal information.
- Before production use, add authentication where needed, privacy controls, logging policy, rate limiting, monitoring, stronger testing, and human-agent escalation.
- Use a production WSGI server and disable debug mode before deployment.

## Project abstract
The AI-Based Customer Support Chatbot is a web application designed to automate responses to frequently asked customer questions. It uses text feature extraction through TF-IDF and a Logistic Regression classifier to predict the intent of a customer's message. The predicted intent is mapped to a response stored in a JSON knowledge base. Flask provides the backend API, while HTML, CSS, and JavaScript create the interactive chat interface. The system can answer common queries related to orders, shipping, returns, refunds, payments, accounts, and warranties. It demonstrates how NLP and supervised machine learning can be applied to customer service automation. The current implementation is a prototype and does not connect to live customer or order databases.
